# Hydra Ax Sweeper
Provides a [`Ax Sweeper`](https://ax.dev/) based Hydra Sweeper supporting parallel execution.

Hydra 1.4 will include the final first-party release, based on the existing
implementation. The plugin code will be removed in the Hydra 1.5 line, and no
first-party releases will be published for Hydra 1.5 or later. Existing PyPI
releases will remain available. See the [retirement issue](https://github.com/hydra-ecosystem/hydra/issues/3506)
for the schedule and invitation for community ownership in a separate repository.

See [website](https://hydra.cc/docs/plugins/ax_sweeper/) for more information
